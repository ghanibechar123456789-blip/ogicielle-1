# دفتر المحل — الإصدار 2 (تصميم «زليج» الجديد)

تطبيق ويب قابل للتثبيت (PWA) لتسيير مبيعات ومخزون وفواتير وديون المحلات الصغيرة. يعمل بدون إنترنت، والبيانات تُحفظ في الجهاز.

## الملفات
index.html · app.css · app.js · fonts/ (خط Cairo محلي ليعمل بدون إنترنت) · sw.js · manifest.webmanifest · الأيقونات (icon-192, icon-512, icon-maskable-512, apple-touch-icon, favicon.ico) · لقطتا الشاشة (screenshot-*.png)

## النشر على GitHub Pages
ارفع محتويات المجلد (الملفات نفسها وليس المجلد) إلى مستودعك واستبدل الملفات القديمة، ثم Commit.
بعد دقيقة يتحدّث التطبيق عند فتحه مع الإنترنت. البيانات المخزّنة لا تتأثر.

## بناء ملف ويندوز (.exe) وأندرويد (.apk)
1. افتح pwabuilder.com والصق رابط تطبيقك.
2. اضغط Package for stores ثم اختر Windows أو Android.
3. حمّل الحزمة: ملف .apk يُثبَّت على الهاتف مباشرة، وملف التثبيت للويندوز يُشغَّل على الحاسوب.

## ما الجديد في التصميم
- هوية بصرية جديدة: زمرّد عميق + زعفران مع نقش نجمة ثمانية مستوحى من الزليج.
- لوحة «مبيعات اليوم» في شاشة البيع (المبلغ وعدد الفواتير والربح).
- بطاقات منتجات بأيقونات حروف ملوّنة، وشريط تنقل عائم على الهاتف، وقائمة جانبية على الحاسوب.
- رسوم بيانية متدرجة، ونوافذ وأزرار بحركات خفيفة، ووضع داكن محسّن.
- أيقونات التطبيق ولقطات الشاشة محدّثة. وظائف التطبيق وبياناتك لم تتغير.
